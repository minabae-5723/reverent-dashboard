B) Key Messages

1. **심텍 2,742억 증설 — 논점은 수요가 아니라 조달로 이동**
   6개사 전원 BUY 유지에 TP 17.0만~19.0만원(현재가 116,900원)으로 수요 자체엔 이견이 없음. 쟁점은 유증을 명시 배제한 상황에서의 조달 구조 — 하나증권 시뮬레이션 기준 전액 CB 조달 시 잠재주식 225만주 + 기존 7회차 CB 232만주로 완전희석 시총 약 4.9조원, 완전희석 PER 12.5배.

2. **SoCAMM은 이제 단일 종목 이벤트가 아니라 밸류체인 테마**
   같은 날 심텍(기판 Capa)·티엘비(쏘캠 믹스, 매출 비중 16%→30%)·피에스케이(전공정 장비) 3건이 동시에 나옴. 티엘비 쏘캠 가이던스는 연초 200억 → 500억 → 700억원으로 8개월 새 3.5배 상향.

3. **SoCAMM TAM을 키운 건 용량 하향이라는 역설**
   SoCAMM당 메모리 용량이 192GB→96GB로 하향되며 동일 총용량 기준 필요 모듈 수가 오히려 증가(메리츠). 여기에 AMD·Qualcomm 랙스케일 채택 검토와 JEDEC LPDDR6 기반 SoCAMM 표준화가 겹침.

4. **화장품은 실적 게임이 끝나고 밸류에이션 게임으로 전환**
   1M 코스피 +0.8% vs 화장품 커버리지 +32.7%로 이미 선반영. 8월 1~20일 캐나다향 수출 비중이 평시 2%에서 13.4%로 튄 건 데이터 오류로 추정되며 9월 1일 하향 수정 가능성 — 수출 모멘텀 지표 자체가 흔들릴 수 있음.

5. **미국 협상 템포 가속 = 유가·장기금리 하향 압력**
   CIA 국장 극비 방러(8/25) + 미중 1.5트랙 대화 개시 + 이란 호르무즈 임시 항로 합의가 한 방향을 가리킴. 9월 24일 미중 정상회담 거론, 과잉생산 관세 7.5% 검토 보도. 미 10년물 4.64% 부근.
